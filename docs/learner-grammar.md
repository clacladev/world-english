# Learner Grammar — World English on One Page

> The whole language, one rule per line. This page is a **scannable summary** for learners: each
> rule is a single statement plus a couple of examples. The full specs — with the problem each
> rule solves, the trade-offs, and the rejected alternatives — are the source of truth; every
> rule below links to its spec. Read this to learn the language; read the specs to understand why.

Rule keys: `O*` [orthography](orthography.md) · `P*` [pronunciation](pronunciation.md) ·
`M*` [morphology](morphology.md) · `G*` [grammar](grammar.md) · `S*` [style](style.md) ·
`W*` [writing](writing.md).

## Spelling

- **[O1](orthography.md#rule-o1--one-dialect-one-spelling) — One spelling.** Use American spelling
  everywhere; the British variant is dropped. *colour → **color***, *centre → **center***.
- **[O2](orthography.md#rule-o2--drop-purely-silent-etymological-letters) — Drop silent letters.**
  Remove purely silent etymological letters. *doubt → **dout***, *debt → **det***.
- **[O3](orthography.md#rule-o3--one-consonant-doubling-rule) — One doubling rule.** Double a final
  consonant only after a stressed single vowel + single consonant. *stop → **stopped***,
  *travel → **traveling*** (unstressed, no doubling).
- **[O4](orthography.md#rule-o4--what-is-deliberately-left-alone) — Left alone.** Spelling is
  regularized only *lightly*; most words keep their familiar shape so the page still reads as
  English.
- **[O5](orthography.md#rule-o5--respell-ough-words-only-where-an-informal-form-already-exists) —
  `ough` respelling.** Respell an `ough` word only where an informal spelling already exists.
  *through → **thru***, *though → **tho***, *although → **altho***.

## Sound

- **[P1](pronunciation.md#rule-p1--every-word-carries-a-respelling) — Respelling.** Every word
  carries a symbol-free respelling: ordinary letters, hyphens between syllables, CAPITALS on the
  stress. *computer → **kom-PYOO-ter***.
- **[P2](pronunciation.md#rule-p2--the-respelling-alphabet-one-symbol-per-sound) — One sound, one
  spelling.** The respelling alphabet gives each sound exactly one spelling. *cat → **KAT***,
  *book → **BUUK*** (vs *moon → **MOON***).
- **[P3](pronunciation.md#rule-p3--th-is-split-in-the-key) — `th` split.** In the key, `th` = /θ/
  (*thin → **THIN***) and `dh` = /ð/ (*this → **DHIS***).
- **[P4](pronunciation.md#rule-p4--stress-is-always-marked-never-guessed) — Stress marked.** Native
  stress is kept and always shown in CAPITALS; noun/verb stress pairs collapse to the noun's
  stress. *present* (gift/give) → both **PREZ-ent**.
- **[P5](pronunciation.md#rule-p5--connected-speech-is-optional-never-required) — Careful speech OK.**
  Weak forms and elision are allowed but never required; the full respelled form is always correct.
- **[P6](pronunciation.md#rule-p6--sentence-rhythm-is-optional-syllable-timing-is-acceptable) —
  Even rhythm OK.** Giving every syllable full weight (syllable-timing) is always intelligible and
  correct.
- **[P7](pronunciation.md#rule-p7--intonation-carries-only-the-question) — Pitch = question.**
  Pitch is load-bearing for one thing only: a spoken yes/no question rises. In writing, a trailing
  `?` marks it.

## Word forms

- **[M1](morphology.md#rule-m1--all-verbs-are-regular) — Regular verbs.** Every past tense and
  participle is `-ed`. No irregular verbs. *go → **goed***, *take → **taked***, *see → **seed***.
- **[M2](morphology.md#rule-m2--one-verb-of-be-regularized) — One `be`.** *be* has one present
  (**be**) and one past (**beed**). *I **be** here. They **beed** late.*
- **[M3](morphology.md#rule-m3--no-third-person--s) — No 3rd-person `-s`.** The present tense has
  one form for every person. *he goes → **he go***, *she tries → **she try***.
- **[M4](morphology.md#rule-m4--all-plurals-are-regular) — Regular plurals.** Every plural is `-s`
  (or `-es` after a sibilant). *child → **childs***, *foot → **foots***, *knife → **knifes***.
- **[M5](morphology.md#rule-m5--one-comparative-rule) — Comparatives.** Both `-er`/`-est` **and**
  `more`/`most` are always valid; suppletives are abolished. *good → **gooder**/**goodest*** (*or*
  *more good*), never *better*.
- **[M6](morphology.md#rule-m6--one-adverb-rule) — Regular adverbs.** Form an adverb with `-ly`,
  always (one exception: *hard*). *good → **goodly***, *fast → **fastly***.

## Sentence

- **[G1](grammar.md#rule-g1--a-leaner-tenseaspect-system) — Tense.** Three tenses (past, present,
  future) + optional `-ing`; **no perfect**. Still true? Use present + a time phrase. Finished?
  Use past + a time word. *I have lived here ten years → **I live here for ten years***; *I have
  finished → **I finished already***.
- **[G2](grammar.md#rule-g2--one-article-rule) — One article.** One article, **the**, for
  known things; nothing for indefinite things. *I saw a dog → **I seed dog***; *the dog barked →
  **the dog barked***.
- **[G3](grammar.md#rule-g3--regular-prepositions-for-time-place-and-verbs) — Prepositions.**
  Time = **on**, location = **in**, motion = **to**; real-relation prepositions keep their meaning;
  a verb keeps its own preposition as vocabulary. *in July → **on July***; *listen **to** music*
  (kept).
- **[G4](grammar.md#rule-g4--regular-pronoun-case) — Pronouns.** Standard pronoun forms;
  *who/whom* → always **who**; *whose* kept. *the man whom I saw → **the man who I seed***.
- **[G5](grammar.md#rule-g5--all-nouns-are-countable) — All nouns count.** Every noun can be
  pluralized; *much* → *many*. *some information → **informations***; *much homework → **many
  homeworks***.
- **[G6](grammar.md#rule-g6--regular-questions-and-negation-no-do-support) — Questions & negation.**
  No *do*, no inversion; a wh-word fronts, the rest keeps SVO; a written question takes a trailing
  `?`; **not** goes before the main verb. *Do you like it? → **You like it?***; *I do not like it
  → **I not like it***.
- **[G7](grammar.md#rule-g7--a-reduced-modal-set-shades-by-adverb) — Modals.** Four modals — **can,
  must, should, will** — with adverbs for finer shades. *It may rain → **Maybe it will rain***.
- **[G8](grammar.md#rule-g8--one-conditional-shape) — Conditionals.** *if* + clause, natural tense,
  no backshift; the result clause takes **will** (real) or **would** (unreal). *If I had money, I
  would buy it → **If I have money, I would buy it***.
- **[G9](grammar.md#rule-g9--passive-voice) — Passive.** **be** + the verb's `-ed`, optional
  *by*-phrase. *The house was built → **The house beed builded***.
- **[G10](grammar.md#rule-g10--noun-possessive) — Noun possessive.** Standard `'s` (singular) and
  `s'` (plural), kept. *the dog's bone*; *the childs' toys*.
- **[G11](grammar.md#rule-g11--subordinate-clauses-introduced-by-that) — `that`-clauses.** One
  word, **that**, introduces every relative and content clause, never dropped, natural tense. *the
  man I saw → **the man that I seed***; *he said it was cold → **he sayed that it beed cold***.
- **[G12](grammar.md#rule-g12--verb-complementation) — Complements.** A verb complement is always
  **to** + base verb (modals and *let/make/see/hear* take the bare verb). *I enjoy swimming → **I
  enjoy to swim***.
- **[G13](grammar.md#rule-g13--subordinating-conjunctions) — Subordinators.** One word per meaning
  (*if, unless, because, altho, when, while, before, after, until, so that, so*), natural tense,
  leading clause takes a comma. *We left because it was late → **We leaved because it beed late***.
- **[S1](style.md#rule-s1--fixed-subjectverbobject-order) — Word order.** Keep Subject → Verb →
  Object; no fronting or inversion. *Never have I seen it → **I never seed it***.
- **[S2](style.md#rule-s2--plain-single-sense-words) — Plain words.** Prefer the plain,
  single-sense word: plain verb over opaque phrasal, clearest sense, literal over idiom, regular
  pairing. *give up → **quit***; *bite the bullet → **accept the hard thing***.
- **[S3](style.md#rule-s3--state-relevance-explicitly-cover-for-the-dropped-perfect) — Time words.**
  Carry "past with present relevance" with a plain time word (*already, since, still, just, yet*).
  *I have finished → **I already finished***.
- **[S4](style.md#rule-s4--one-default-adverb-position) — Adverb slot.** Put a manner/frequency/
  degree adverb immediately before the main verb. *He drives carefully → **He carefully drive***.
- **[S5](style.md#rule-s5--politeness-markers-and-speech-act-templates) — Politeness.** Fixed
  markers (**please / sorry / thank you**) and one plain template per speech act, never graded
  indirectness. *Could you possibly send the file? → **Please send the file.***

## Writing

- **[W1](writing.md#rule-w1--one-regular-punctuation-set) — Punctuation.** One mark, one job: no
  semicolon; the colon only introduces a list; the comma has one closed set of jobs (boundary /
  list / set-off).
- **[W2](writing.md#rule-w2--one-plain-register) — One register.** One neutral register — you write
  the same way to a professor and to a friend.
- **[W3](writing.md#rule-w3--state-the-main-point-first-thesis-first-linear-shape) — Point first.**
  State the main point first, then support it.
- **[W4](writing.md#rule-w4--one-idea-per-paragraph-topic-sentence-first) — One idea per paragraph.**
  Each paragraph covers one idea; its first sentence states it.
- **[W5](writing.md#rule-w5--make-every-connection-explicit) — Explicit links.** Bind sentences with
  one explicit connective per relation (*and, but, so, because, for example, then*); never leave the
  link implicit.
- **[W6](writing.md#rule-w6--repeat-dont-vary-keep-every-reference-clear) — Repeat, don't vary.**
  Repeat a noun rather than swapping in synonyms; keep every pronoun's antecedent unmistakable.
